### Ambiente Virtual
Inicie um ambiente virtual dentro da pasta do projeto, digite os seguintes comandos:
<pre>
  python -m venv .venv
  
  .\.venv\Scripts\activate
  
  pip install -r .\requirements.txt
</pre>

### Interpretador
Tente rodar qualquer célula do <a href='https://github.com/nicolasfouv/metodos-numericos-para-equacoes-diferenciais/blob/main/main.ipynb'>main.ipynb</a> e selecione o interpredador do ambiente virtual (de caminho .\\.venv\Scripts\python). Após isso, todo o arquivo está pronto para ser rodado.
